# 电力负荷预测实训任务描述（模型训练部分）

## 一、任务背景

在电力负荷预测项目中，**模型训练**是核心环节，直接决定最终预测精度。本阶段任务是在完成数据预处理和特征工程的基础上，选择合适的机器学习模型，训练并优化模型参数，最终建立高精度的电力负荷预测模型。

### 1. 业务需求
准确预测电力负荷对于电网调度、电力市场交易、可再生能源消纳等具有重要意义。本项目的业务目标为：
- **日均负荷预测误差（MAPE）≤ 15%**
- **日最高/最低负荷预测误差（MAPE）≤ 20%**
- **模型训练时间 ≤ 30分钟**（满足日内滚动预测需求）

### 2. 技术挑战
- **非线性关系**：电力负荷与气象、时间等特征间存在复杂的非线性关系。
- **时序依赖性**：负荷数据具有强时序依赖性（自相关性），需选择合适模型捕获此特性。
- **过拟合风险**：训练集样本量有限（约2200个样本），复杂模型容易过拟合。
- **模型选择困难**：需从众多机器学习模型中，选择最适合电力负荷预测的模型。

from sklearn.metrics import r2_score, mean_squared_error, mean_absolute_error

def evaluate_model(model, X, y):
    y_pred = model.predict(X)
    r2 = r2_score(y, y_pred)
    rmse = np.sqrt(mean_squared_error(y, y_pred))
    mae = mean_absolute_error(y, y_pred)
    mape = np.mean(np.abs((y - y_pred) / y)) * 100
    return {'R²': r2, 'RMSE': rmse, 'MAE': mae, 'MAPE': mape}

# 评估所有模型

### 步骤5：统计检验
**输入**：各模型的验证集预测结果  
**输出**：统计检验报告

**工作内容**：
1. 实现**DM检验**（Diebold-Mariano Test）
2. 实现**改进DM检验**（修正小样本偏差）
3. 实现**Mantesta检验**（比较预测相关性）
4. 分析检验结果，判断模型性能差异是否显著

**关键代码**：
```python
# DM检验实现
def dm_test(y_true, y_pred1, y_pred2):
    # 计算预测误差
    e1 = y_true - y_pred1
    e2 = y_true - y_pred2
    d = (e1 ** 2) - (e2 ** 2)  # 误差平方差
    
    # 计算DM统计量
    n = len(d)
    d_mean = np.mean(d)
    d_var = np.var(d) / n
    dm_stat = d_mean / np.sqrt(d_var)
    
    # p-value（双侧检验）
    p_value = 2 * (1 - stats.norm.cdf(abs(dm_stat)))
    return dm_stat, p_value

# 应用DM检验
y_val_pred_ridge = best_ridge.predict(X_val)
y_val_pred_rf = best_rf.predict(X_val)
dm_stat, p_value = dm_test(y_val, y_val_pred_ridge, y_val_pred_rf)
print(f"DM检验统计量：{dm_stat:.4f}, p-value：{p_value:.4f}")
```

## 六、任务风险与应对

### 风险1：验证集样本量不足
**可能性**：高（验证集仅27个样本）  
**影响**：统计检验功效不足，无法证明模型间显著差异  
**应对措施**：
- 扩大验证集时间跨度（从7天扩展到14天）
- 使用Bootstrap方法估计性能置信区间
- 在报告中明确说明统计检验的局限性

### 风险2：模型过拟合
**可能性**：中（训练集R²高，验证集R²低）  
**影响**：模型泛化性能差，预测精度低  
**应对措施**：
- 增加正则化强度（L2正则化、早停）
- 使用交叉验证选择最优超参数
- 绘制学习曲线，监控过拟合/欠拟合

### 风险3：训练效率低
**可能性**：中（XGBoost训练时间超过10分钟）  
**影响**：超参数调优耗时长，影响项目进度  
**应对措施**：
- 使用并行计算（`n_jobs=-1`）
- 使用随机搜索替代网格搜索
- 降低交叉验证折数（从10折到5折）
