### 作业 1：宽表转长表与日聚合

**任务描述**：原始负荷数据为宽表格式（每行一天，每列一个 15 分钟时间点），需转换为长表后按日聚合。

**核心代码**：
```python
# 宽表转长表
long_df = load_raw.melt(
    id_vars="YMD", value_vars=time_cols, 
    var_name="time_slot", value_name="load"
)
# 按日聚合
daily = (
    long_df.groupby("YMD", as_index=False)
    .agg(load_max=("load", "max"), 
         load_min=("load", "min"), 
         load_mean=("load", "mean"))
    .merge(weather_raw, on="YMD", how="left")
)
```

**处理结果**：
- 原始数据：每日 96 个时间点（15 分钟间隔）
- 聚合后：每日 3 个目标变量（日最高、最低、平均负荷）
- 时间范围：2009 年至 2015 年，共约 1800 + 天

### 作业 2：异常值诊断与成因分类

**方法**：使用 IQR（Interquartile Range）方法检测异常值。
```python
q1 = train[col].quantile(0.25)
q3 = train[col].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
```

**异常值成因分类**：
| 成因 | 天数 | 处理方式 |
|--------|------|----------|
| 春节 | 约 30 天 | 保留（真实极端事件）|
| 国庆节 | 约 9 天 | 保留（真实极端事件）|
| 元旦 | 约 3 天 | 保留（真实极端事件）|
| 劳动节 | 约 3 天 | 保留（真实极端事件）|
| 极端高温（>30°C）| 少量 | 保留（天气异常）|
| 极端低温（<5°C）| 少量 | 保留（天气异常）|

**决策**：所有异常值均保留，因为均为真实极端事件，非数据质量问题。

### 作业 3：特征工程

**构造的特征类别**：

1. **日历周期特征**（6 个）：
   - `month_sin`, `month_cos`：月份周期编码（12 个月）
   - `dow_sin`, `dow_cos`：星期周期编码（7 天）
   - `doy_sin`, `doy_cos`：年内日期周期编码（365 天）
   - `is_weekend`：周末标识

2. **气象衍生特征**（3 个）：
   - `temp_range = temp_max - temp_min`：昼夜温差
   - `HDD = max(18 - temp_avg, 0)`：采暖度日（Heating Degree Days）
   - `CDD = max(temp_avg - 26, 0)`：制冷度日（Cooling Degree Days）

3. **滞后与滚动统计特征**（18 个）：
   - `load_*(lag_1|7|14)`：前 1 天、7 天、14 天的负荷值
   - `load_*(roll_mean|std_7|14)`：7 日、14 日滚动均值与标准差

**总特征数**：22 个（3 个气象 + 6 个日历 + 3 个衍生 + 18 个滞后/滚动 = 30，但实际因目标不同略有差异）

### 作业 7：Diebold-Mariano（DM）检验

**目的**：考虑误差序列的自相关结构，检验两个模型的预测能力是否有显著差异。

**代码实现**：
```python
def diebold_mariano_test(actual, forecast1, forecast2, horizon=1, loss="MSE"):
    # 计算损失差异
    if loss == "MSE":
        d = (actual - forecast1) ** 2 - (actual - forecast2) ** 2
    elif loss == "MAE":
        d = abs(actual - forecast1) - abs(actual - forecast2)
    
    # Newey-West 长程方差估计
    d_mean = np.mean(d)
    gamma_0 = np.var(d, ddof=0)
    long_run_var = gamma_0
    for k in range(1, min(horizon, n-1) + 1):
        gamma_k = np.mean((d[k:] - d_mean) * (d[:-k] - d_mean))
        weight = 1.0 - k / (horizon + 1.0)
        long_run_var += 2.0 * weight * gamma_k
    
    # DM 统计量
    dm_stat = d_mean / np.sqrt(long_run_var / n)
    p_value = 2.0 * (1.0 - norm.cdf(abs(dm_stat)))
    return dm_stat, p_value
```

**结果**：

| 目标 | DM 统计量 | P 值 | 结论（α=0.05） |
|------|----------|-------|------------------|
| 日平均负荷 | X.XXXX | **0.000216** | **预测能力差异显著** |
| 日最高负荷 | -X.XXXX | 0.258019 | 差异不显著 |
| 日最低负荷 | -X.XXXX | 0.070126 | 差异不显著 |

**解读**：

- 日最高/最低负荷：RMSE 更优，但 DM 检验未达显著（可能因验证集仅 183 天，统计功效不足）

### 作业 10：残差自相关检验（Ljung-Box）

**目的**：检测残差是否存在未捕捉的时序依赖。

**代码**：
```python
from statsmodels.stats.diagnostic import acorr_ljungbox

for lag in [1, 7, 14]:
    lb_result = acorr_ljungbox(residuals, lags=[lag], return_df=True)
    lb_stat = lb_result.iloc[0]["lb_stat"]
    lb_p = lb_result.iloc[0]["lb_pvalue"]
```

**结果**：
- lag=1：部分目标存在显著自相关（p < 0.05）→ 提示可能遗漏短期依赖特征
- lag=7：部分目标存在显著自相关 → 提示可能遗漏周周期特征
- lag=14：自相关较弱

**改进方向**：后续可加入"节后恢复"和"夜间负荷变化"特征。

### 作业 11：异方差检验（Breusch-Pagan）

**目的**：检测残差方差是否随拟合值变化。

**结果**：
- 部分目标存在显著异方差（p < 0.05）
- **影响**：对树模型无影响；若使用线性模型（Ridge），需使用加权最小二乘或稳健标准误

### 作业 13：物理约束修正

**问题**：模型可能预测出 `load_min > load_mean` 或 `load_max < load_mean` 的不合理结果。

**修正策略**：
```python
# 计算历史负荷差值的中位数（作为合理 gap 参考）
max_gap = (load_max - load_mean).median()
min_gap = (load_mean - load_min).median()

# 修正
pred_df.loc[pred_df["pred_load_min"] > pred_df["pred_load_mean"], "pred_load_min"] = \
    pred_df["pred_load_mean"] - min_gap

pred_df.loc[pred_df["pred_load_max"] < pred_df["pred_load_mean"], "pred_load_max"] = \
    pred_df["pred_load_mean"] + max_gap
```

## 七、实训问题与解决方案

### 问题 1：验证集样本量不足导致统计检验功效低

**现象**：日最高和日最低负荷的 DM 检验 p 值 > 0.05，未能拒绝原假设（即未能证明 Stacking 显著优于 XGBoost）。

**原因分析**：
- 验证集仅 183 天
- 统计检验需要更大样本量才能达到较高功效（Power Analysis 显示需要约 300-500 天）

**解决方案**：
- 如实汇报结果："Stacking 的 RMSE 更低，但 DM 检验未达显著（p = 0.258），可能因验证集样本量不足"
- 在学术写作中避免"接受原假设"，而是说"未能拒绝原假设"

### 问题 2：特征共线性严重（VIF > 10）

**现象**：计算方差膨胀因子（VIF）发现部分特征 VIF > 10，表明存在严重共线性。

**解决方案**：
- 树模型（RandomForest、XGBoost、Stacking）对共线性天然不敏感 → 无需处理
- Ridge 回归的 L2 正则化可缓解系数膨胀 → 无需处理
- 放弃使用 OLS 线性回归（不在主方案中）

### 问题 3：Optuna 调参耗时过长

**现象**：每个模型 × 每个目标 50 次 trial，共 750 次训练，耗时较长。

**解决方案**：
- 使用 CUDA 加速 XGBoost（`device="cuda"`）
- 设置 `n_jobs=1` 避免 CPU 超线程竞争
- 使用 `MedianPruner` 提前终止无望 trial
- V5 版本支持"仅生成报告"模式（不重新训练）
