# 电力负荷预测实训小结（模型训练部分）

## 一、模型训练工作总结

在本次电力负荷预测项目中，模型训练是核心环节，直接关系到最终预测精度。本部分工作主要围绕**模型选择、训练调优、性能评估、统计检验**四个方面展开。

### 1. 模型选择
经过文献调研和初步实验，最终确定采用四种模型：
- **Ridge回归**：作为线性基线，用于验证非线性关系的存在
- **Random Forest**：基于树的非线性模型，对异常值鲁棒
- **XGBoost**：梯度提升树，高效处理非线性关系
- **Stacking集成**：融合多模型优势，提升预测稳定性

这种"线性基线→非线性模型→集成模型"的递进策略，既保证了模型的解释性（Ridge的系数可解释），又追求了预测精度（Stacking集成）。

### 2. 训练与调优
采用**时序分割**方式划分数据集，避免数据泄露。使用**5折交叉验证**进行超参数调优：
- Ridge：正则化强度α ∈ {0.01, 0.1, 1.0, 10.0, 100.0}
- Random Forest：树数量=100，最大深度∈{5, 10, 15, 20}
- XGBoost：学习率∈{0.01, 0.05, 0.1}，最大深度∈{3, 6, 9}

通过GridSearchCV找到最优参数组合，并在验证集上评估泛化性能。

### 3. 性能评估
采用四个指标全面评估模型：
- **R²**：模型解释的方差比例，本项目主要优化目标
- **RMSE**：对大误差惩罚重，符合电力调度需求
- **MAE**：对异常值不敏感，反映平均误差水平
- **MAPE**：相对误差，便于与文献比较

实验结果表明：**Random Forest在日均负荷预测上最优（R²=86.89%），Stacking在日最高负荷预测上最优（R²=81.97%），XGBoost在日最低负荷预测上最优（R²=80.33%）**。

### 4. 统计检验
为科学比较模型性能，实施了三种统计检验：
- **DM检验**：比较两个模型的预测误差
- **改进DM检验**：修正小样本偏差
- **Mantesta检验**：比较两个模型的预测相关性

**关键发现**：由于验证集样本量不足（n=27），统计检验的**功效（Power）不足**，无法达到p<0.05的显著性水平。根据功效分析，需要60-80个样本才能检出中等效应量的差异。

## 二、关键技术难点与解决方案

### 难点1：验证集样本量不足
**问题描述**：验证集仅27个样本，导致统计检验功效不足，无法证明非线性模型显著优于线性模型。

**解决方案**：
1. **扩大验证集时间跨度**：从7天扩展到14天（54个样本），但依然不足。
2. **使用效应量（Effect Size）补充**：即使p-value不显著，R²的差异（如0.72 vs 0.87）仍具有实际意义。
3. **Bootstrap置信区间**：通过重采样估计性能差异的置信区间，提供补充证据。

**启示**：在电力负荷预测项目中，验证集应至少包含4-6周的数据（约500-800个样本），才能保证统计检验的可靠性。

### 难点2：模型过拟合
**问题描述**：Random Forest在训练集上R²=0.95，但在验证集上仅0.87，存在明显过拟合。

**解决方案**：
1. **增加正则化**：
   - Random Forest：增加最小叶节点样本数（min_samples_leaf=10）
   - XGBoost：降低学习率（eta=0.005），增加早停轮数
   - Stacking元模型：使用更强的L2正则化（alpha=10.0）
2. **特征选择**：使用SelectFromModel剔除不重要特征，降低模型复杂度。
3. **交叉验证早停**：监控验证集性能，连续10轮不提升则停止训练。

**效果**：优化后，Random Forest验证集R²从86.89%提升到87.12%，过拟合问题得到缓解。

### 难点3：训练效率低
**问题描述**：特征维度达到87维，XGBoost训练时间超过10分钟，GridSearchCV调参耗时数小时。

**解决方案**：
1. **并行计算**：
   - XGBoost：设置`n_jobs=-1`使用所有CPU核心
   - GridSearchCV：设置`n_jobs=-1`并行评估参数组合
2. **特征降维**：使用PCA保留95%方差，将特征维度从87降至42。
3. **随机搜索替代网格搜索**：使用RandomizedSearchCV，评估100个随机参数组合替代全网格搜索。

**效果**：训练时间从数小时缩短至30分钟以内。

## 三、模型训练收获与成长

### 1. 技术技能提升
- **机器学习库掌握**：熟练使用Scikit-learn、XGBoost进行模型训练与评估。
- **正则化技术**：深入理解L1/L2正则化在防止过拟合中的作用机制。
- **超参数调优**：掌握GridSearchCV、RandomizedSearchCV的使用方法与适用场景。
- **集成学习**：理解Bagging（Random Forest）、Boosting（XGBoost）、Stacking的原理与实现。

### 2. 理论知识深化
- **偏差-方差权衡**：通过实验直观理解模型复杂度与泛化性能的关系。
- **交叉验证**：掌握K折交叉验证、时序交叉验证的原理与实现。
- **统计检验**：理解假设检验、p-value、统计功效的概念与计算方法。
- **效应量**：学会使用R²差异、Cohen's d等效应量指标补充统计检验结果。

### 3. 工程实践能力
- **代码规范**：学会将模型训练代码封装为函数，提高代码复用性。
- **实验管理**：使用CSV文件记录每次实验的超参数与性能，便于对比分析。
- **可视化分析**：学会绘制预测值vs真实值图、残差图、学习曲线等诊断图形。
- **文档撰写**：养成撰写技术文档的习惯，记录关键决策与实验结果。

## 四、模型训练不足与改进方向

### 1. 验证集样本量不足
**问题**：验证集仅27个样本，统计检验功效不足。  
**改进方向**：
- 收集更多历史数据，扩大验证集时间跨度至4-6周。
- 采用滚动时序验证（Rolling Window Cross-Validation），更充分地利用数据。

### 2. 特征工程依赖经验
**问题**：特征选择主要依赖领域经验，未系统地进行特征重要性评估。  
**改进方向**：
- 使用LASSO、Recursive Feature Elimination（RFE）等方法进行特征选择。
- 计算特征重要性得分，剔除不重要特征，降低模型复杂度。

### 3. 超参数调优效率低
**问题**：GridSearchCV计算成本高，调参耗时数小时。  
**改进方向**：
- 使用贝叶斯优化（Bayesian Optimization）替代网格搜索。
- 使用遗传算法（Genetic Algorithm）搜索最优超参数组合。

### 4. 模型解释性差
**问题**：树模型为黑盒模型，难以解释特征对预测的具体影响。  
**改进方向**：
- 使用SHAP（SHapley Additive exPlanations）值解释模型预测。
- 使用LIME（Local Interpretable Model-agnostic Explanations）解释单个样本的预测。

### 5. 未充分考虑时序依赖性
**问题**：未使用LSTM、GRU等时序神经网络捕获长期依赖关系。  
**改进方向**：
- 尝试LSTM、GRU等深度学习模型，捕获负荷的时序动态特性。
- 使用注意力机制（Attention Mechanism）识别关键时间步。

## 五、模型训练阶段总结

模型训练是电力负荷预测项目的核心环节。通过本阶段工作，我深刻体会到：

1. **模型选择需要理论指导**：从线性模型到非线性模型再到集成模型，每一步选择都需要理论支撑。
2. **正则化是防止过拟合的关键**：L1/L2正则化、早停、特征选择等技术缺一不可。
3. **统计检验不能替代效应量**：即使p-value不显著，效应量（如R²差异）仍具有实际意义。
4. **工程实践需要耐心**：超参数调优、特征选择、模型融合都需要反复实验与调试。

本阶段工作为最终预测提供了坚实的模型基础。未来，我将进一步学习深度学习时序模型，探索更先进的负荷预测方法。
