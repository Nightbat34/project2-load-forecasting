# 电力负荷预测实训作业记录（模型训练部分）

## 一、模型训练阶段工作内容

### 1. 模型选择与设计
**完成时间**：第3周  
**工作内容**：
- 确定采用Ridge回归、Random Forest、XGBoost、Stacking集成四种模型
- 设计对比实验方案：单一模型 vs 集成模型
- 确定评估指标体系：R²、RMSE、MAE、MAPE

**技术要点**：
- Ridge回归作为线性基线，L2正则化强度α通过交叉验证选择
- Random Forest设置树数量=100，最大深度=10，最小叶节点样本数=5
- XGBoost设置学习率=0.01，子树采样率=0.8，列采样率=0.8
- Stacking采用5折交叉验证生成元特征，元模型为Ridge回归

---

### 2. 模型训练与调参
**完成时间**：第4周  
**工作内容**：
- 实现四种模型的训练代码
- 使用GridSearchCV进行超参数调优
- 记录各模型在训练集、验证集上的性能

**关键代码**：
```python
# Ridge回归调参
from sklearn.linear_model import Ridge
from sklearn.model_selection import GridSearchCV

ridge = Ridge()
param_grid = {'alpha': [0.01, 0.1, 1.0, 10.0, 100.0]}
grid_search = GridSearchCV(ridge, param_grid, cv=5, scoring='r2')
grid_search.fit(X_train, y_train)
best_ridge = grid_search.best_estimator_
```

**训练结果**（验证集R²）：
- Ridge：0.7234
- Random Forest：0.8689
- XGBoost：0.8033
- Stacking：0.8197（日最高负荷）

---

### 3. 模型评估与分析
**完成时间**：第4周  
**工作内容**：
- 计算四个评估指标（R²、RMSE、MAE、MAPE）
- 绘制预测值 vs 真实值散点图
- 分析各模型在不同负荷类型（日均、最高、最低）上的表现差异

**关键发现**：
1. Random Forest在日均负荷预测上表现最佳（R²=86.89%）
2. Stacking在日最高负荷预测上表现最佳（R²=81.97%）
3. XGBoost在日最低负荷预测上表现最佳（R²=80.33%）
4. 线性模型（Ridge）性能显著低于非线性模型，证明电力负荷与特征间存在非线性关系

---

### 4. 统计检验实施
**完成时间**：第5周  
**工作内容**：
- 实现DM检验、改进DM检验、Mantesta检验
- 计算各模型间的统计显著性差异
- 分析检验结果不显著的原因（验证集样本量不足）

**检验结果**：
- Ridge vs Random Forest：p-value = 0.1023（不显著）
- Ridge vs XGBoost：p-value = 0.0847（不显著）
- Random Forest vs Stacking：p-value = 0.1532（不显著）

**问题诊断**：
- 验证集仅27个样本，统计检验功效（Power）不足
- 根据功效分析，需要60-80个样本才能达到p<0.05的显著性水平
- 样本量不足导致无法证明非线性模型显著优于线性模型

---

### 5. 模型优化与正则化
**完成时间**：第5周  
**工作内容**：
- 针对过拟合问题，调整各模型的正则化参数
- 对Random Forest增加最小叶节点样本数（从5调整到10）
- 对XGBoost增加早停轮数（从50到100）
- 对Stacking的元模型（Ridge）加强L2正则化

**优化效果**（验证集R²变化）：
- Random Forest：86.89% → 87.12%（+0.23%）
- XGBoost：80.33% → 80.67%（+0.34%）
- Stacking：81.97% → 82.35%（+0.38%）

---

## 二、模型训练关键技术难点与解决方案

### 难点1：验证集样本量不足导致统计检验不显著
**问题描述**：验证集仅27个样本，统计检验功效不足，无法证明模型间显著差异。

**解决方案**：
1. 扩大验证集时间跨度（从7天扩展到14天，获得54个样本）
2. 采用Bootstrap方法估计性能分布的置信区间
3. 在报告中明确说明统计检验的局限性，主要依赖效应量（R²差异）而非p-value

---

### 难点2：模型过拟合训练集
**问题描述**：Random Forest在训练集上R²=0.95，但在验证集上仅0.87。

**解决方案**：
1. 增加Random Forest的最小叶节点样本数（min_samples_leaf=10）
2. 降低XGBoost的学习率（eta=0.005）并增加树的数量
3. 对Stacking的元模型使用更强的L2正则化（alpha=10.0）
4. 使用早停（early stopping）防止XGBoost过拟合

---

### 难点3：特征维度高导致训练速度慢
**问题描述**：特征工程后特征维度达到87维，XGBoost训练时间超过10分钟。

**解决方案**：
1. 使用特征选择方法（SelectFromModel）剔除不重要特征
2. 对Random Forest使用特征子集采样（max_features='sqrt'）
3. 对XGBoost使用并行计算（n_jobs=-1）
4. 减少交叉验证折数（从10折到5折）
