# 电力负荷预测项目问答（模型训练部分）

## 1. 项目采用了哪些预测模型？为什么选择这些模型？

本项目采用了四种回归模型：Ridge回归、Random Forest、XGBoost以及Stacking集成模型。

**选择依据**：
- **Ridge回归**：作为线性基线模型，用于处理特征间的多重共线性问题，通过L2正则化防止过拟合。
- **Random Forest**：非线性模型，能够处理特征间的复杂交互关系，对异常值不敏感，提供特征重要性评估。
- **XGBoost**：梯度提升树的高效实现，在处理非线性关系和特征交互方面表现优异，且训练速度快。
- **Stacking集成**：结合多个基模型的预测能力，通过元模型（Ridge）学习如何最佳组合基模型预测，以提升泛化性能。

这种模型选择策略符合数据挖掘项目的最佳实践：从简单线性模型开始建立基线，然后引入非线性模型捕获复杂模式，最后通过集成学习进一步提升性能。

## 2. 如何划分训练集、验证集和测试集？这种划分方式有什么优势？

本项目采用**时序分割（Time Series Split）**方式：
- **训练集**：2009年初至2015年1月10日的历史数据
- **验证集**：2015年1月11日至1月17日（共7天，非连续选取）
- **测试集**：2015年1月18日至1月24日（共7天，非连续选取）

**优势**：
1. **避免数据泄露**：严格按时间顺序划分，确保训练集的时间范围完全在验证集和测试集之前，符合电力负荷预测的实际应用场景。
2. **模拟实际预测**：验证集和测试集选取未来时段，检验模型的时序泛化能力。
3. **充足的训练样本**：训练集包含约6年的数据（约2200个样本），足够训练复杂的非线性模型。

**局限性**：验证集仅7天（27个样本）导致统计检验功效不足，需要60-80个样本才能达到p<0.05的显著性水平。

## 3. Random Forest和XGBoost的原理是什么？它们在处理非线性问题上有何优势？

### Random Forest原理
Random Forest是一种**集成学习**方法，通过构建多棵决策树并取其预测平均值：
1. **Bootstrap采样**：对训练集进行有放回抽样，生成多个子训练集。
2. **随机特征选择**：在每个节点分裂时，随机选择部分特征进行最优分裂。
3. **多树集成**：所有决策树的预测结果取平均（回归）或投票（分类）。

### XGBoost原理
XGBoost（eXtreme Gradient Boosting）是一种**梯度提升**算法：
1. **加法模型**：按顺序构建多棵决策树，每棵树学习前一棵树的残差。
2. **目标函数**：包含损失函数和正则化项，防止过拟合。
3. **二阶泰勒展开**：利用损失函数的一阶和二阶导数进行优化。
4. **并行计算**：特征排序后并行寻找最优分裂点。

### 处理非线性问题的优势
- **无需特征变换**：树模型自动学习特征的非线性变换，无需手动进行多项式展开或对数变换。
- **捕获特征交互**：通过树结构自动捕获特征间的复杂交互作用（如温度与湿度的联合影响）。
- **适应异质性**：电力负荷在不同时段、不同季节的模式差异巨大，树模型能够自适应地划分特征空间。

## 4. 为什么Stacking集成模型的性能优于单一模型？

Stacking通过**元学习**策略，组合多个基模型的优势：

**本项目的Stacking架构**：
- **基模型（Base Models）**：Ridge、Random Forest、XGBoost
- **元模型（Meta Model）**：Ridge回归
- **训练方式**：使用交叉验证预测作为新特征，训练元模型学习如何加权组合基模型预测。

**性能提升的原因**：
1. **偏差-方差权衡**：不同模型具有不同的偏差-方差特性。Ridge偏差高但方差低，XGBoost偏差低但方差高。Stacking通过加权组合，降低整体泛化误差。
2. **错误多样性**：基模型在不同样本上犯错，元模型学会在基模型预测不一致时进行校正。
3. **正则化效果**：使用Ridge作为元模型，避免对基模型预测赋予过大的权重，防止过拟合。

**实际效果**：Stacking在日最高负荷预测上达到81.97%的R²，优于任何单一模型。

## 5. 如何评估模型性能？为什么选择R²和RMSE作为评估指标？

本项目使用四个评估指标：
- **R²（决定系数）**：表示模型解释的方差比例，越接近1越好。
- **RMSE（均方根误差）**：预测值与真实值的标准差，单位与原始数据相同（MW）。
- **MAE（平均绝对误差）**：预测误差的绝对值平均，对异常值不敏感。
- **MAPE（平均绝对百分比误差）**：相对误差的平均值，便于跨尺度比较。

**选择R²和RMSE的原因**：
1. **R²**：直观反映模型拟合优度，便于与文献中的其他方法比较。
2. **RMSE**：对大误差惩罚更重，符合电力负荷预测的实际需求（大误差会导致严重的调度问题）。

**评估结果**（验证集性能）：
- 日均负荷：Random Forest最佳（R²=86.89%）
- 日最高负荷：Stacking最佳（R²=81.97%）
- 日最低负荷：XGBoost最佳（R²=80.33%）

## 6. 统计检验（DM检验、改进DM检验、Mantesta检验）的作用是什么？结果如何解读？

统计检验用于**科学地比较模型性能**，判断性能差异是否由随机性引起。

### DM检验（Diebold-Mariano Test）
- **原假设**：两个模型的预测误差无显著差异。
- **备择假设**：一个模型的预测误差显著低于另一个。
- **结果解读**：若p-value < 0.05，则拒绝原假设，认为模型性能有显著差异。

### 改进DM检验（Modified DM Test）
- 考虑了DM检验在小样本下的偏差，通过修正方差估计提高检验准确性。
- 适用于本研究的小样本验证集（n=27）。

### Mantesta检验（Mantel Test）
- 用于比较两个模型的预测误差相关性，判断它们是否捕获了相同的模式。
- 若两个模型的预测误差高度相关，则它们可能基于相同的特征子集。

**本项目结果**：
- 由于验证集样本量不足（n=27），统计检验的**功效（Power）不足**，无法达到p<0.05的显著性水平。
- 根据统计功效分析，需要60-80个样本才能达到足够的检验功效。
- 因此，虽然Stacking的R²高于单一模型，但统计检验无法证明其显著性。

## 7. 模型训练过程中如何处理过拟合问题？

本项目采用多种正则化策略防止过拟合：

### Ridge回归
- **L2正则化**：在损失函数中添加参数平方和的惩罚项。
- **参数调优**：通过交叉验证选择最优正则化强度α。

### Random Forest
- **树的数量**：使用100棵树，降低方差。
- **最大深度**：限制树的最大深度，防止过拟合。
- **最小叶节点样本数**：设置叶节点最小样本数，避免学习噪声。

### XGBoost
- **学习率（eta）**：设置为0.01，小步长逐步优化。
- **子树采样率（subsample）**：0.8，随机选取80%的样本训练每棵树。
- **列采样率（colsample_bytree）**：0.8，随机选取80%的特征。
- **早停（early stopping）**：若验证集性能连续多轮不提升，则停止训练。

### Stacking
- **交叉验证生成元特征**：使用5折交叉验证生成基模型预测，避免信息泄露。
- **Ridge作为元模型**：L2正则化防止对基模型预测过拟合。

## 8. 为什么选择2015年1月11-17日作为验证集？这对模型训练有何影响？

### 选择原因
1. **时序连续性**：验证集紧接训练集末尾，模拟实际预测场景。
2. **时段代表性**：1月中旬涵盖冬季典型负荷模式（供暖需求高）。
3. **足够的时间跨度**：7天的数据包含工作日和周末，能够检验模型的日周期性适应能力。

### 对模型训练的影响
**负面影响**：
- **样本量不足**：仅27个样本（每天96个点，7天×96=672，但只选取了27个时点）导致：
  1. 模型性能评估的方差大，不稳定。
  2. 统计检验功效不足，无法证明模型间显著差异。
  3. 超参数调优容易受到抽样误差影响。

**改进建议**：
- 扩大验证集至4-6周（约500-800个样本）。
- 采用滚动时序验证（Rolling Window Cross-Validation）。
- 在模型选择时，更多依赖交叉验证性能而非单一验证集。

## 9. 模型训练的代码实现有哪些关键技术细节？

### 数据预处理
```python
# 宽表转长表（Wide to Long）
df_melted = pd.melt(df, id_vars=['Date', 'Time'], var_name='Variable', value_name='Value')
```

### 特征工程
```python
# 周期性编码（24小时周期）
df['Hour_sin'] = np.sin(2 * np.pi * df['Hour'] / 24)
df['Hour_cos'] = np.cos(2 * np.pi * df['Hour'] / 24)

# 气象特征（Heating/Cooling Degree Days）
df['HDD'] = np.maximum(df['Temperature'] - 65, 0)  # 供暖需求
df['CDD'] = np.maximum(65 - df['Temperature'], 0)  # 制冷需求

# 滞后特征（Autocorrelation）
for lag in [1, 2, 3, 24, 48, 168]:  # 1小时、2小时、3小时、1天、2天、1周
    df[f'Load_lag_{lag}'] = df['Load'].shift(lag)
```

### 模型训练
```python
# Ridge回归
from sklearn.linear_model import Ridge
model = Ridge(alpha=1.0)
model.fit(X_train, y_train)

# Random Forest
from sklearn.ensemble import RandomForestRegressor
model = RandomForestRegressor(n_estimators=100, max_depth=10, random_state=42)
model.fit(X_train, y_train)

# XGBoost
from xgboost import XGBRegressor
model = XGBRegressor(n_estimators=100, learning_rate=0.01, max_depth=6)
model.fit(X_train, y_train)

# Stacking
from sklearn.ensemble import StackingRegressor
base_models = [
    ('ridge', Ridge()),
    ('rf', RandomForestRegressor()),
    ('xgb', XGBRegressor())
]
meta_model = Ridge()
model = StackingRegressor(estimators=base_models, final_estimator=meta_model)
model.fit(X_train, y_train)
```

### 模型评估
```python
from sklearn.metrics import r2_score, mean_squared_error
y_pred = model.predict(X_test)
r2 = r2_score(y_test, y_pred)
rmse = np.sqrt(mean_squared_error(y_test, y_pred))
```

## 10. 未来可以如何改进模型训练？

1. **扩大验证集**：增加至4-6周，提高统计检验功效。
2. **深度学习模型**：尝试LSTM、GRU等时序神经网络，捕获长期依赖关系。
3. **特征选择**：使用LASSO、Recursive Feature Elimination等方法，剔除冗余特征。
4. **超参数自动调优**：使用Bayesian Optimization或Genetic Algorithm替代网格搜索。
5. **多任务学习**：同时预测日均、最高、最低负荷，共享特征表示。
6. **异常检测**：在训练前剔除异常负荷数据（如节假日、极端天气），避免模型学习噪声。
