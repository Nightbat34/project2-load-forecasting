# 数据挖掘实训 — 任务描述

## 一、项目背景

电力系统调度运行高度依赖短期负荷预测结果，用于指导机组启停、燃料采购与电网安全校核。负荷预测按时间尺度可分为超短期（分钟级）、短期（1–7 天）、中期（月度）和长期（年度）。本项目聚焦于**短期日负荷预测**，基于 2009–2015 年历史数据，分别预测未来某日的**日最高负荷**、**日最低负荷**和**日平均负荷**。

## 二、数据说明

| 项目 | 内容 |
|------|------|
| 数据文件 | `附件1-电网负荷数据.xlsx` |
| 负荷 sheet | `Area_Load`：每日 96 点（15 分钟间隔）负荷曲线 |
| 气象 sheet | `Area_Weather`：日最高温、最低温、平均气温、湿度、降雨量 |
| 时间范围 | 2009 年至 2015 年 |
| 训练期 | 2012-01-15 至 2014-06-30 |
| 验证期 | 2014-07-01 至 2014-12-31（约 183 天）|
| 预测目标 | 2015-01-11 至 2015-01-17（7 天）|

## 三、核心任务

### 任务 1：数据预处理与探索性分析

1. **宽表转长表**：使用 `pd.melt` 将 96 列时间点转换为长格式，再按日聚合得到日最高、最低、平均负荷。
2. **缺失值处理**：检查气象与负荷变量的缺失情况，采用合理策略填补或剔除。
3. **异常值诊断**：使用 IQR 方法检测异常负荷日，并结合节假日日历（春节、国庆、元旦、劳动节）与极端气温进行分类标注。
4. **七步前置检查**：按照统计学习规范，依次完成 Y 变量类型判断、Y 分布诊断、离散度与异常值、共线性检查（VIF、Pearson 高相关）、显著性水平设定、残差分析方案设计、建模路线图制定。

### 任务 2：特征工程

1. **日历周期特征**：对 `month`、`dayofweek`、`day_of_year` 进行 sin/cos 编码，捕捉年周期与周周期。
2. **气象衍生特征**：
   - `temp_range = temp_max - temp_min`（昼夜温差）
   - `HDD = max(18 - temp_avg, 0)`（采暖度日）
   - `CDD = max(temp_avg - 26, 0)`（制冷度日）
3. **滞后与滚动统计特征**：对三个预测目标分别构造 lag-1、lag-7、lag-14 及 7 日、14 日滚动均值/标准差，以利用负荷的短期自相关。
4. **节假日特征**：`is_weekend` 标识周末效应。

### 任务 3：模型训练与超参数优化

| 模型 | 类型 | 关键超参数 | 优化方法 |
|------|------|------------|----------|
| Ridge | 线性 + L2 正则 | `alpha` | Optuna（50 trials）|
| RandomForest | Bagging 树集成 | `n_estimators`, `max_depth`, `min_samples_leaf` | Optuna（50 trials）|
| XGBoost | Boosting 树集成（CUDA） | `n_estimators`, `learning_rate`, `subsample` | Optuna（50 trials）|
| SVR | 核方法（RBF） | `C`, `gamma`, `epsilon` | Optuna（50 trials）|
| KNN | 距离相似日匹配 | `n_neighbors`, `weights` | Optuna（50 trials）|
| Stacking | 集成学习 | 5 个基模型 + Ridge 元学习器 | 3-Fold CV |

- **时间序列交叉验证**：使用 `TimeSeriesSplit(n_splits=3)` 保证训练集时间早于验证集，避免未来信息泄露。
- **Bootstrap OOB 估计**：重复采样评估泛化误差置信区间。

### 任务 4：统计检验与模型选择

1. **配对 T 检验**：比较最优模型与次优模型的绝对误差均值差异。
2. **McNemar 检验**：基于 5% 相对误差容忍度，比较两个模型的"犯错模式"是否显著不同。
3. **Diebold-Mariano（DM）检验**：考虑误差序列的自相关结构，检验两个模型的预测能力是否有显著差异（Newey-West 长程方差估计）。
4. **Friedman 检验**：多模型非参数排名检验，判断是否存在显著差异。
5. **PAC（近似正确概率）**：验证集上相对误差 ≤ 5% 的天数占比，用于业务解释。

### 任务 5：残差诊断

对最终选择的 Stacking 模型进行残差分析：

1. **正态性检验**：Shapiro-Wilk、D'Agostino-Pearson、Kolmogorov-Smirnov 检验。
2. **自相关检验**：Ljung-Box 检验（lag=1, 7, 14），检查残差是否存在未捕捉的时序依赖。
3. **异方差检验**：Breusch-Pagan 检验，检查残差方差是否随拟合值变化。
4. **可视化诊断**：残差直方图 + KDE、Q-Q 图、残差 vs 拟合值散点图、残差时序图。

### 任务 6：递推预测与物理约束修正

1. **递推预测**：对于 2015-01-11 至 2015-01-17 的 7 天预测，每日预测需要用到之前日的预测值来构造滞后特征，因此采用逐日递推方式。
2. **物理约束修正**：
   - 强制 `load_min ≤ load_mean ≤ load_max`
   - 强制所有预测负荷 > 0
   - 使用训练期负荷差值的中位数作为修正参考 gap

## 四、评估指标

| 指标 | 公式 | 业务含义 |
|------|------|----------|
| RMSE | √(MSE) | 惩罚大误差，对极端预测偏差敏感 |
| MAE | mean(\|y - ŷ\|) | 对异常值鲁棒，反映平均偏差 |
| MAPE | mean(\|y - ŷ\| / y) × 100% | 相对误差，便于业务方理解 |
| R² | 1 - (MSE / var(y)) | 模型解释的方差比例 |
| PAC@5% | P(\|y - ŷ\| / y ≤ 0.05) | 相对误差不超过 5% 的概率 |
