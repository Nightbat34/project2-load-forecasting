Integration

后续网页合并与模型调用说明

静态展示合并

直接复制整个 Short-term Power Load Forecasting System 文件夹即可。页面入口是 frontend/index.html， 数据统一在 assets/data/dashboard_data.json，图片在 assets/images，样式和脚本在 assets/css 与 assets/js。

模型接口预留

三个 Stacking 模型已放入 models/。后续若要做后端预测服务， 可读取 code/project2_forecast_v5_base.py 中的特征工程和 project2_model_manifest.csv 中的特征列表。

维护建议

展示层不重新训练模型，避免部署不稳定。若要替换模型结果，只更新 CSV 后重新生成 dashboard_data.json，网页结构无需改动。
