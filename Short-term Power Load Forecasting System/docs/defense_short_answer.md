# 答辩简版：V6 过拟合与集成问题

1. 训练集和验证集没有日期重合。训练集为 2012-01-15 至 2014-06-30，验证集为 2014-07-01 至 2014-12-31。
2. Stacking 训练集平均 R² 为 0.9889，验证集平均 R² 为 0.8546，说明存在一定过拟合倾向。
3. 过拟合主要来自滞后/滚动特征很强、树模型容量较高、样本量只有 911 天、验证期季节分布与训练期不同。
4. 但验证集 R² 仍约 0.85，MAPE 约 4% 左右，所以不是严重过拟合，而是“训练拟合强、泛化仍可接受”。
5. 模型集成的问题是 StackingRegressor(cv=3) 默认不是时间序列交叉验证，对时序预测不够严谨；并且部分基模型预测高度相关，集成增益有限。
6. 后续可将 Stacking 内部 CV 改为 TimeSeriesSplit，精简基模型，并降低 XGBoost/RandomForest 的复杂度。
